# SignWise Competition Video Script

Target: 2 minutes 20 seconds. Maximum: 3 minutes.

## Shot list

### 0:00–0:15 — The problem

Show the agreement, human-only signature block, and 4-tool badge.

> Electronic signing made the final click easy, but consequential fine print is still easy to miss. SignWise brings an AI reviewer into the live agreement without letting it consent for you.

### 0:15–0:30 — Live page context

Open **Review with agent** and hold on 4 → 6.

> The page exposes four safe read tools. Opening this live review workspace adds two contextual capabilities tied to the agreement I’m actually viewing.

### 0:30–0:45 — Natural request

Send the first prompt from the runbook.

> I ask for an outcome in ordinary language. I name no tool, schema, or planted issue—and I reserve acceptance and signing for myself.

### 0:45–1:10 — Agent investigation

Show clause reads arriving in Agent activity, then findings appearing beside the document.

> The agent reads the contract through structured page tools and adds evidence-backed findings directly beside the clauses. There is no canned risk scan hidden in the page.

### 1:10–1:35 — Human approval

Show the editable proposal, change one phrase, save, then approve. Hold on 7 tools.

> The agent prepares a review, not a signature. I can edit, dismiss, or approve it. Approval binds only this exact revision and exposes one narrowly scoped completion capability.

### 1:35–1:48 — Natural continuation

Send `Approved.`

> The proposal reference remains between the page and agent. I only communicate fresh approval.

### 1:48–2:05 — Verifiable result

Show the record, fingerprint, human-only Continue button, and count returned to 4.

> The page records the exact approved review and immediately shows version-bound evidence. The agent never signs; the final action is mine.

### 2:05–2:20 — Close

Overlay: `Live agreement → Agent evidence → Human approval → Human signature`.

> SignWise shows why WebMCP matters: the agent works inside the web application’s live context while the application protects the human decision boundary.

End on the live URL and public repository. Export H.264 MP4 at 1080p with captions and verify public playback while signed out.
